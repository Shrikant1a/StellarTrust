## Summary of Changes
- **Security**: Added reentrancy guards to the core escrow contract, and optimized Gas fees for Mainnet executions.
- **Assets**: Integrated USDC alongside native XLM payments for stable transaction routing.
- **Features**: Launched the Trust & Reputation Scoring (TRS) system, integrated Freighter/Albedo/Stellar Wallet Kit integrations, and added print-friendly exports, network fee estimation tools, and USD converters.
- **Monitoring & Compatibility**: Expanded monitoring with a dynamic client-side Network Toggle (Testnet/Mainnet support) enabling real-time metrics switching and network RPC latency tracking.
